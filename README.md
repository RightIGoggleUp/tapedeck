# TapeDeck (test build)

Cassette-style music player for Android foldables, built for the Motorola Razr Fold.
Open: tape shelf plus the deck. Closed: the cassette plays on the cover screen, keys under the reels, tape moves left to right over the length of the album.
Playback engine: libVLC (LGPL 2.1). Original art and synthesized sounds only.
